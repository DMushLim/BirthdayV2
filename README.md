# BirthdayV2
Do you have a special person who is having a birthday today or soon? So that might be useful for you.

BirthdayV2, as the name says, is the second version of my project.
## Write a letter, gather some photos
You can use this 'template' for someone's birthday. The files are  all instructed about what you need to change: colors, messages, images.
Feel free to modify, edit, correct, or even make your own version inspired on mine, and please, let me know if you do.

I don't have much experience with JavaScript and CSS animations, so I used Artificial Intelligence (Github Copilot) on these.
