# BirthdayV2
Do you have a special someone celebrating a birthday today or soon? If so, this might be useful for you.

BirthdayV2, as the name suggests, is the second version of my project.
## Write a letter, gather some photos
You can use this 'template' for someone's birthday. The files include instructions on everything you need to change: colors, messages, images.
Feel free to modify, edit, correct, or even make your own version inspired by mine, and please, let me know if you do.

I don't have much experience with JavaScript and CSS animations, so I used Artificial Intelligence (Github Copilot) for those parts.
